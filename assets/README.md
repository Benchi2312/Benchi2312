# Recursos del perfil

- `profile-banner.svg`: banner vectorial original para el encabezado. Actualiza el texto y los colores aquí si cambian el nombre o la dirección visual.
- `mesora-demo-dashboard.png`: captura real del dashboard administrativo en `https://mesora-sistema.vercel.app/demo/admin`, tomada en modo demo con datos de ejemplo.
- `icons/`: iconos de marca locales de Simple Icons y Devicon, teñidos de azul para mantener una presentación uniforme. Están guardados aquí para que el README no dependa de carga remota de iconos.
